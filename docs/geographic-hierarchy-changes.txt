MIEJSCA DO DALSZEJ MODYFIKACJI (wskaże użytkownik)
----------------------------------------------------
Ustawienie geographicHierarchy jest przechowywane w bazie danych jako string.

Odczyt w komponencie klienckim (przez publiczne API):
  const res = await fetch("/api/settings")
  const data = await res.json()
  const hierarchy = data.geographicHierarchy  // "voivodeships" | "counties" | "cities"

Odczyt po stronie serwera (Prisma):
  const setting = await prisma.settings.findUnique({ where: { key: "geographicHierarchy" } })
  const hierarchy = setting?.value ?? "voivodeships"
