## ARCHITEKTURA BAZY DANYCH

### Model: HelpCategory

**Lokalizacja:** `/prosta-sprawa/prisma/schema.prisma` (linie 1389-1430)

```prisma
model HelpCategory {
  id          String   @id @default(uuid())
  nazwa       String                    // Nazwa kategorii, np. "Pytania Ogólne"
  slug        String   @unique          // URL-friendly identyfikator
  opis        String?                   // Opcjonalny opis kategorii
  ikona       String?                   // Nazwa ikony z biblioteki Lucide
  kolejnosc   Int      @default(0)     // Kolejność wyświetlania
  aktywna     Boolean  @default(true)  // Czy kategoria jest widoczna

  // Relacje
  questions   HelpQuestion[]           // Lista pytań w kategorii

  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([aktywna])
  @@index([kolejnosc])
}
```

**Cechy:**
- **Unikalne slug:** Automatycznie generowane z nazwy, polskie znaki konwertowane
- **Ikony Lucide:** Obsługa nazw ikon z biblioteki Lucide React (np. "QuestionMarkCircle", "CreditCard")
- **Sortowanie:** Według pola `kolejnosc` (rosnąco)
- **Soft visibility:** Pole `aktywna` pozwala ukryć kategorię bez usuwania

### Model: HelpQuestion

**Lokalizacja:** `/prosta-sprawa/prisma/schema.prisma` (linie 1432-1452)

```prisma
model HelpQuestion {
  id          String   @id @default(uuid())
  categoryId  String
  category    HelpCategory @relation(fields: [categoryId], references: [id], onDelete: Cascade)

  pytanie     String                   // Treść pytania
  odpowiedz   String                   // Odpowiedź (obsługa HTML/Markdown)
  slug        String   @unique         // URL-friendly identyfikator
  kolejnosc   Int      @default(0)    // Kolejność w kategorii
  aktywna     Boolean  @default(true) // Czy pytanie jest widoczne

  // Statystyki
  wyswietlenia Int     @default(0)    // Liczba wyświetleń
  pomocne     Int      @default(0)    // Liczba "pomocne"
  niepomocne  Int      @default(0)    // Liczba "niepomocne"

  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([categoryId])
  @@index([aktywna])
  @@index([kolejnosc])
}
```

**Cechy:**
- **Cascade Delete:** Usunięcie kategorii automatycznie usuwa wszystkie pytania
- **Statystyki:** Tracking wyświetleń i feedbacku (pomocne/niepomocne)
- **Slug unikalny:** Pozwala na bezpośrednie linkowanie do pytań (#slug)
- **HTML/Markdown:** Pole `odpowiedz` obsługuje formatowany tekst

**Pola formularza:**
- **Nazwa** (wymagane)
  - Automatycznie generuje slug podczas wpisywania

- **Slug** (wymagane)
  - Automatycznie generowany z nazwy
  - Można edytować ręcznie
  - Walidacja: tylko małe litery, cyfry i myślniki (regex: `^[a-z0-9-]+$`)
  - Unikalność sprawdzana w API

- **Opis** (opcjonalne)
  - Textarea z możliwością zmiany rozmiaru
  - Krótki opis kategorii

- **Ikona** (opcjonalne)
  - Nazwa ikony z biblioteki Lucide
  - Przykłady: "Package", "CreditCard", "QuestionMarkCircle"
  - Podpowiedź: "Nazwa ikony z biblioteki Lucide"

- **Kolejność** (wymagane)
  - Type: number
  - Domyślna wartość: 0
  - Określa kolejność wyświetlania (rosnąco)

- **Aktywna** (boolean)
  - Switch toggle
  - Domyślnie: true
  - Czy kategoria jest widoczna dla użytkowników

**Funkcje specjalne:**
1. **Auto-generowanie slug:**
   - Konwersja polskich znaków (ą→a, ć→c, ę→e, ł→l, ń→n, ó→o, ś→s, ź→z, ż→z)
   - Małe litery
   - Spacje → myślniki
   - Usunięcie znaków specjalnych
   - Przykład: "Pytania Ogólne" → "pytania-ogolne"

2. **Usuwanie kategorii:**
   - Dialog potwierdzenia
   - Ostrzeżenie: "Wszystkie pytania z tej kategorii również zostaną usunięte"
   - Operacja nieodwracalna
   - Cascade delete przez relację w bazie

### FUNKCJONALNOŚCI

#### 1. Wyszukiwarka
- **Pozycja:** Na górze strony
- **Placeholder:** "Czego szukasz?"
- **Ikona:** 🔍 Search (Lucide)
- **Funkcja:**
  - Przeszukuje zarówno pytania jak i odpowiedzi
  - Case-insensitive
  - Filtrowanie w czasie rzeczywistym
  - Współpraca z filtrem kategorii

**Implementacja:**
```typescript
const matchesSearch = searchQuery === "" ||
  q.pytanie.toLowerCase().includes(searchQuery.toLowerCase()) ||
  q.odpowiedz.toLowerCase().includes(searchQuery.toLowerCase())
```

#### 2. Filtrowanie kategorii
- **Przyciski:** "Wszystkie" + dynamiczna lista kategorii
- **Style:**
  - Aktywny filtr: `variant="default"` (niebieski)
  - Nieaktywny: `variant="outline"` (biały z obramowaniem)
- **Funkcja:**
  - Wyświetla tylko pytania z wybranej kategorii
  - "Wszystkie" pokazuje pytania ze wszystkich kategorii
  - Pokazuje tylko kategorie które mają aktywne pytania

#### 3. Accordion FAQ
- **Biblioteka:** Radix UI Accordion
- **Type:** "single" (tylko jedno pytanie otwarte naraz)
- **Collapsible:** true

**Każde pytanie zawiera:**
- **Trigger (nagłówek):**
  - Ikona ❓ HelpCircle (Lucide)
  - Treść pytania (bold)
  - Badge z nazwą kategorii (outline variant)

- **Content (rozwinięcie):**
  - Odpowiedź wyrenderowana jako HTML (`dangerouslySetInnerHTML`)
  - Style prose (Tailwind Typography)
  - Przycisk "Kopiuj link" z ikoną 🔗

#### 4. Deep Linking (Linkowanie do pytań)
- **Mechanizm:** Anchor links z użyciem slug (#slug)
- **Funkcja kopiowania:**
  ```typescript
  const url = `${window.location.origin}${window.location.pathname}#${slug}`
  navigator.clipboard.writeText(url)
  ```
- **Feedback:** Toast "Link skopiowany do schowka"
- **Auto-scroll:** Po załadowaniu strony przewija do pytania z hasha

**Implementacja auto-scroll:**
```typescript
useEffect(() => {
  if (window.location.hash) {
    const hash = window.location.hash.substring(1)
    setTimeout(() => {
      const element = document.getElementById(hash)
      if (element) {
        element.scrollIntoView({ behavior: "smooth", block: "center" })
      }
    }, 300)
  }
}, [categories])
```

## BEZPIECZEŃSTWO I UPRAWNIENIA

### Autoryzacja
- **Admin Panel:** Wymaga roli `ADMIN`
- **Public View:** Dostępne dla zalogowanych użytkowników kancelarii
- **API Admin:** Sprawdzenie `session.user.role === "ADMIN"`
- **API Public:** Brak wymagań autoryzacyjnych

### Walidacja danych
- **Zod schemas:** Walidacja po stronie klienta
- **API validation:** Sprawdzenie unikalności slug, istnienia powiązań
- **SQL Injection:** Zabezpieczone przez Prisma ORM
- **XSS:** Użycie `dangerouslySetInnerHTML` dla odpowiedzi (zaufana treść od adminów)

### Cascade Delete
- Usunięcie kategorii → automatyczne usunięcie pytań
- Relacja: `onDelete: Cascade` w schemacie Prisma
- Ostrzeżenie w UI przed usunięciem kategorii
